Purdue automatic sign-in

Settings stay in this Chrome profile. The extension runs only on Purdue SSO and Microsoft sign-in pages. Anyone with access to this Chrome profile may be able to recover the password and authenticator secret.

At Microsoft Security info, add a different authenticator app and choose Can’t scan QR Code? Paste its secret key above. Keep your existing sign-in method until the new one is verified. A current six-digit code is not the secret key.
