Purdue automatic sign-in

Settings stay in this browser profile. Anyone with access to this profile may be able to recover the password and authenticator secret.

Set up automatic sign-in

  1. After updating the extension files, reload it in chrome://extensions (Chrome) or about:debugging#/runtime/this-firefox (Firefox). Reload any open sign-in tabs too.
  2. At Microsoft Security info, sign in with your existing method. Choose + Add sign-in method → Microsoft Authenticator → I want to use a different authenticator app → Can’t scan QR Code? Purdue’s guide shows this path. A URL beginning mobileappcommunicator.auth.microsoft.com/activatev2 means you are in Microsoft Authenticator setup; go back and choose the different-app link.
  3. Copy the Secret key into the field below. Enter your career account and password, choose your campus, and enable automatic sign-in. Valid changes save automatically. Use the current code to verify the new method on Microsoft’s page; the code refreshes automatically. Keep your old method until verification succeeds.
  4. Start sign-in from Purdue Brightspace or another Purdue service. Use the button in the extension popup to enable or disable automatic sign-in. Green means enabled; gray means disabled. When disabled, use the website’s own account controls to choose another account.

The extension fills sign-in forms and selects your configured campus and account. It does not sign you out or clear browser data. If a stale sign-in session causes trouble, use your browser's site-data controls for the affected Purdue, Brightspace, and Microsoft sites.

A current six-digit code is not the setup key. Never share the setup key in chat or a pull request.
